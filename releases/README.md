# Mizuki Booking Bridge releases

## Version 1.18.2

Upload `mizuki-booking-bridge-1.18.2.zip` in WordPress under Plugins, Add New, then Upload Plugin.

This release reads WooCommerce price ranges, lets variable price workshops open their product page, and protects calendar checkout products from purchases without a valid session hold. The studio can choose the checkout route for each paid workshop in Settings. Calendar checkout products should be Simple and Virtual, with WooCommerce stock management off; the calendar controls seats per session.

The booking API and studio dashboard from the same release must be deployed before enabling calendar checkout protection on a product.

## Version 1.18.0

Upload `mizuki-booking-bridge-1.18.0.zip` in WordPress under Plugins, Add New, then Upload Plugin.

This release adds WooCommerce product link setup, automatic product price display, passwordless workshop booking, group participant booking, and direct checkout handoff.

The checksum file can be used to verify that the downloaded archive is unchanged.
